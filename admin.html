How to publish an edit: make changes here, download site-content.json, then replace that file in the GitHub repository and commit it. The published portal updates after GitHub Pages finishes deploying. Do not put access tokens or sensitive information in this file.

Link/Button URLs should be https://…, http://…, or a relative website path. A GitHub Pages site cannot reliably open Windows UNC paths such as \\server\share; use an approved intranet/SharePoint URL instead.
